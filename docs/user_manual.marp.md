# MyGPT User Manual

ASE 285 Individual Project

---

## What Is MyGPT?

MyGPT is a simple chatbot application.

It is based on a ChatGPT clone prototype and uses the OpenAI API.

The app adds user-friendly features such as help, search, bookmarks, documents, and UI settings.

---

## Start the App

1. Open the project.
2. Go to the `src` folder.
3. Run `npm install`.
4. Add an OpenAI API key.
5. Run `npm run dev`.


---

## Send a Message

1. Type a prompt in the message box.
2. Press Enter or click the send icon.
3. Wait for the AI response.

Use Shift + Enter to add a new line.

---

## Use Help

Click the `?` button at the top right.

The help overlay shows short tips for important controls.

Click anywhere or press any key to close it.

---

## Use Settings

Click the settings button at the top right.

You can change the font size.

The app saves the selected font size and uses it later.

---

## Use the Sidebar

The sidebar shows saved conversations.

You can:

- Start a new chat
- Select an old conversation
- Search conversations
- Open bookmarks
- Open documents
- Delete all conversations
- Collapse or open the sidebar

---

## Rename a Conversation

Click the pencil icon on a conversation row.

Type a new title.

Press Enter or click outside the input to save it.

---

## Search Conversations

1. Open the search page from the sidebar.
2. Type a keyword.
3. Press Enter.
4. Click a result to open the conversation.

---

## Bookmark Messages

Click the bookmark icon on a message.

Open the Bookmarks page to see all bookmarked messages.

Click a bookmarked item to open the related conversation.

---

## Use Documents

Open the Documents page from the sidebar.

You can:

- Add a document
- Edit a document
- Delete a document

---

## Use Documents in Prompts

1. Click the document icon left-side of the message input.
2. Select one or more documents.
3. Type your prompt.
4. Send the message.
